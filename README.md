# sneakers-connector 🐹

> 🧭 Sneakers connector: built-in and remote workers that test and rotate credentials on target systems

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-connector
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
